# Learning

## What is this for?

This folder is for anyone on the Pequautobots team who is learning Java and how to code the robot. In this folder, there are subfolders with student names. In each subfolder, any student can write code to learn basic Java, test out ideas, or just mess around with code. No changes made in this folder are saved to the GitHub repository. Consequently, any changes made here are not available on other people's computers and are tied to the device that they are made on. If you use different computers, the changes made on one device are not available on another.
