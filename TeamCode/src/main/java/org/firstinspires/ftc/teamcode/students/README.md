# Students

## What is this for?

This folder is for anyone on the Pequautobots team who is learning Java and how to code the robot. In this folder, there are subfolders with student names. In each subfolder, any student can write code to learn basic Java, test out ideas, or just mess around with code. 

**Note on Git:** To keep our repository clean, only the `README.md` files in this directory are saved to GitHub. Any `.java` files you create here stay on your local computer. If you work on different laptops, your practice code will not automatically follow you.
